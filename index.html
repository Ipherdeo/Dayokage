Approach

Work from constraints to a testable result.

01

Clarify the system

I map users, inputs, outputs, data ownership, and likely failure points before treating code as the answer.

02

Build the smallest useful version

I choose straightforward tools, explicit interfaces, and an implementation that can be tested without guesswork.

03

Verify in context

I check real behaviour, correct weaknesses in access or integration, and document what the result can and cannot claim.
